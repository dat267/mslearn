# Protect devices using Microsoft Intune

Notes from the six-module Microsoft Learn learning path **Protect devices using Microsoft Intune**. The material maps to MD-102 Endpoint Administrator; Defender investigation units also support SC-200.

Completed 2026-09-29.
Achievement: https://learn.microsoft.com/api/achievements/share/en-us/DatDo-7483/VSY3VCWM?sharingId=15FA99AA28223E58

Each module note contains main takeaways, detailed notes, knowledge-check answers with distractor reasoning, and a self-check.

## Modules

1. [Endpoint security with Microsoft Defender and Microsoft Intune](01-defender-endpoint-security.md)  
   Defender capabilities and architecture, Intune-versus-Defender responsibilities, onboarding via EDR policy, security baselines, incident triage, and automated investigation and remediation. Achievement: https://learn.microsoft.com/api/achievements/share/en-us/DatDo-7483/ABUNJZ87?sharingId=15FA99AA28223E58

2. [Device encryption and security policies](02-device-encryption-bitlocker.md)  
   BitLocker policy settings, Automatic Device Encryption, Personal Data Encryption, recovery key escrow and rotation, readiness and status reporting, and Defender auditing. Achievement: https://learn.microsoft.com/api/achievements/share/en-us/DatDo-7483/9AB5MHGU?sharingId=15FA99AA28223E58

3. [Advanced threat protection](03-advanced-threat-protection.md)  
   Defense in depth, cloud app discovery, attack surface reduction and audit-first rollout, Zero Trust, and proactive remediation. Achievement: https://learn.microsoft.com/api/achievements/share/en-us/DatDo-7483/WM59BWWN?sharingId=15FA99AA28223E58

4. [Compliance enforcement and remediation](04-compliance-remediation.md)  
   Configuration versus compliance, platform-specific checks and machine risk, group and filter targeting, noncompliance actions, Remediations, and reporting. Achievement: https://learn.microsoft.com/api/achievements/share/en-us/DatDo-7483/NQGH5VAF?sharingId=15FA99AA28223E58

5. [Secure mobile access with Microsoft Tunnel](05-tunnel-mobile-access.md)  
   Linux gateway deployment, configurations and sites, VPN profiles, Tunnel for MAM on unenrolled BYOD, monitoring, `mst-cli`, and log troubleshooting. Achievement: https://learn.microsoft.com/api/achievements/share/en-us/DatDo-7483/ZJNQ3L52?sharingId=15FA99AA28223E58

6. [Cloud PKI](06-cloud-pki.md)  
   Cloud-hosted CA hierarchy, BYOCA, licensing, trust deployment, SCEP, enrollment, revocation, CRL behavior, and certificate health. Achievement: https://learn.microsoft.com/api/achievements/share/en-us/DatDo-7483/K9VXKW7B?sharingId=15FA99AA28223E58
